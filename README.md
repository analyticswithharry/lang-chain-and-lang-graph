# LangChain and LangGraph

Comprehensive tutorials for LangChain and LangGraph frameworks for building LLM applications.

## Contents

- **langchain-end-to-end.ipynb**: Complete LangChain guide with agents, chains, and production patterns
- **langgraph-end-to-end.ipynb**: LangGraph workflow and state management tutorial

## Getting Started

1. Install required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the notebooks:
   ```bash
   jupyter notebook langchain-end-to-end.ipynb
   jupyter notebook langgraph-end-to-end.ipynb
   ```

## Prerequisites

- Python 3.8+
- Jupyter notebook
- LangChain framework
- LangGraph framework
- API keys for LLM services
